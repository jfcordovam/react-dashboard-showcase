# SaaS Dashboard (React + TypeScript + Tailwind + Chart.js)

A responsive SaaS analytics dashboard built with **React**, **TypeScript**, **Tailwind CSS**, and **Chart.js**.  
This project is part of my development portfolio and showcases a basic layout and data visualization setup for a modern web app.

## Features

- Bar charts using Chart.js to display SaaS metrics (e.g. active users, churn, subscriptions)
- Built with React and Vite for fast development
- Styled with Tailwind CSS
- Tested with Vitest (unit testing setup included)
- ESLint + Prettier + TypeScript for clean, consistent code

## 🚀 Getting Started

1. **Install dependencies**

```bash
npm install
```

2. **Start the development server**
```bash
npm run dev
```

3. **Run tests**
```bash
npm run test
```
## Tech Stack
- React + Vite
- TypeScript
- Tailwind CSS
- Chart.js (via react-chartjs-2)
- ESLint / Prettier / Vitest

### Notes

This project is not meant for production use — it is a simplified, static dashboard for demonstration purposes only.
